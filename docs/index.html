为什么需要「图提取」？

电商详情页的图片往往分散在多个懒加载节点中，无法一键批量保存，且格式、命名不统一。

图片分散难收集

商品主图、详情长图、SKU 图散落在页面各处，手动右键保存效率极低。

无法批量保存

缺少统一的采集入口，逐张下载费时费力，还容易遗漏关键图片。

格式命名不统一

JPG、WebP 混杂，文件名乱码，整理归档困难。图提取统一转 PNG 并自动编号。

核心功能

从提取到下载，一条龙搞定

六个核心能力，覆盖商品素材采集的完整流程。

一键提取

自动扫描页面所有商品图，兼容 srcset、data-src 等懒加载属性。

智能过滤

自动排除图标、logo、占位图及小于 100×100 的无效小图。

集中预览

新标签页网格化展示所有图片，附带尺寸信息，一目了然。

自由勾选

支持全选、反选与按需勾选，只下载你真正需要的图片。

统一 PNG

自动将 JPG、WebP 等格式统一转换为 PNG，便于二次处理。

批量下载

一键保存到本地，文件名自动编号，下载过程带进度提示与结果反馈。

快速上手

四步完成安装

无需构建、无需登录，双击即可运行。

  1. 1

    下载并解压

    下载插件压缩包，解压到本地文件夹（如 imagegrab/）。

  2. 2

    打开扩展管理页

    打开 Chrome，地址栏输入 chrome://extensions 回车。

  3. 3

    开启开发者模式

    点击页面右上角的「开发者模式」开关。

  4. 4

    加载扩展

    点击「加载已解压的扩展程序」，选择刚才解压的文件夹即可。
